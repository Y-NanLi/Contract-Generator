# Contract-Generator 合同 / 报价单生成器

单文件离线网页版报价单生成器，版式按「安驰报价单模板」重排，A4 纵向一页。
不联网、不装软件、数据只存本机浏览器。

## 功能

- 客户 / 我方双栏信息，单号按规则自动生成，日期自动带出
- 明细逐行录入（名称、型号、数量、单价），行金额、合计、人民币大写自动计算
- 含税价 / 未税价口径切换：选未税时自动按 13% 加税并单列税额
- 说明条款可改（交期、发票、质保等）
- 自动存本地草稿；「备份」页支持 JSON 导出 / 导入、CSV 导出
- 右上「打印 / 导出 PDF」，A4 纵向一页
- 快捷键：`Ctrl+S` 保存，`Ctrl+P` 打印

## 使用

1. 用 Edge 或 Chrome 打开 `报价单生成器.html`（双击即可，无需服务器）
2. 左侧依次填「单据」→「明细」→「条款」
3. 右上点「打印 / 导出 PDF」

打印设置：纸张 A4、纵向、缩放 100%、取消页眉页脚、不勾「背景图形」。

## 数据与备份

数据只存浏览器 localStorage，不会上传。换电脑或清理浏览器数据前，
先在「备份」页导出 `.json`，在新机器打开本文件后导入即可恢复。
