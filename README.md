# Contract-Generator 合同 / 报价单生成器

单文件离线网页版报价单生成器，版式按「安驰报价单模板」重排，A4 纵向一页。
不联网、不装软件、数据只存本机浏览器。支持捷信通 / 悦智乐 / 安驰多家公司主体。

## 功能

- **公司主体切换**：捷信通 / 悦智乐 / 安驰 / 只要文字，一键换页首 logo 与发件单位抬头
- 客户 / 我方双栏信息，单号按规则自动生成，日期自动带出
- 明细逐行录入（名称、型号、数量、单价），行金额自动计算；编辑区右下角实时显示合计，单据上不印合计与大写金额
- 明细支持从 Excel 批量粘贴（Tab / 逗号分隔）、回车跳下一行同列、填完自动补空行
- 行操作统一放在表格上方：点任意一行选中（选中行整行变蓝），再用「↑ 上移 / ↓ 下移 / ✕ 删除本行」；选中行按 Delete 也能直接删，不再每行挂按钮
- 数量默认留空（不再预填 1），数量与单价都填了才算金额
- 打印明细只输出真正填了内容的行：删掉的行不会残留，空白行也不打印（一条都没填时才留 1 行空框）；编辑区末尾始终留 1 行空白方便继续填
- 含税价 / 未税价口径切换：只影响表头与编辑区合计，不影响版式
- 条款可增可删（交货期 / 发票 / 有效期 + 自定义条款），序号自动顺排，留空不打印
- 打印明细表列宽可调：直接拖「明细」表头的竖线改列宽，只影响这条线和它右边相邻的一格，其他列不动；表格始终按容器宽度铺满、不会出现横向滚动条，打印表按比例同步；双击竖线或「列宽恢复默认」复位
- 明细表格内长名称 / 长型号自动换行，不截断；「关于」等字段同理
- 自动存本地草稿；「备份」页支持 JSON 导出 / 导入、CSV 导出；「导出全部」把单据、记录库、货品库、客户历史一次带走，「导入货品库」可单独迁移货品
- 右上「打印 / 导出 PDF」，A4 纵向一页
- 快捷键：`Ctrl+S` 保存，`Ctrl+P` 打印

### v2.0 新增

- **货物明细库（记忆）**：明细行填齐「规格 + 名称 + 单价」后自动入库（上限 1000 条，同规格合并、最近使用的排前面）；下次只打字就能带出名称和上次单价
- **规格联想**：在「规格型号」格输入时弹出候选（前缀 / 包含 / 空格分词 / 逐字顺序四档匹配，最多 8 条），↑↓ 选择、Enter 补全、Esc 关闭，行尾 ✕ 可直接删掉不要的货品；选中后自动填名称与上次单价（已填的不覆盖）
- **单据记录库**（左侧「记录」）：以前开过的单据全部存着，点「载入」回到原样，「复制成新单」自动换新单号与今天的日期；可按客户 / 单号搜索，列表显示行数与金额；删除给 6 秒撤销
- **版式**（左侧「版式」）：标题 / 信息栏 / 明细三块字号分开调（60–200%），一键「预设」=135/130/115，可复位 100%；「上下偏移」±10mm 整体上下挪动且总高不变、仍是单页；「表格铺到纸底」在明细少时把格线画到页面下方（窗口窄到预览收起时也能正确补行）
- **打印前确认**：打印前弹 4 项检查（A4 纵向 / 边距无 / 取消页眉页脚 / 缩放 100%）；勾「以后不再显示」需手抄「我已阅读且明白」并等满 20 秒，防止手滑关掉提醒（可在版式页重新打开）
- **打印文件名**：自动命名为「客户名 + 单号」（去掉文件名非法字符），导出的 PDF 不用再手动改名
- **输入历史**：收件单位 / 联系人 / 电话三格带下拉候选，取自以前开过的单据（各存最近 30 条）
- **撤销条**：删货品、删记录后底部出现 6 秒撤销条，点一下即还原


## 使用

1. 用 Edge 或 Chrome 打开 `报价单生成器.html`（双击即可，无需服务器）
2. 「我方信息」里先选公司主体，再依次填「单据」→「明细」→「条款」
3. 右上点「打印 / 导出 PDF」

打印设置：纸张 A4、纵向、缩放 100%、取消页眉页脚、不勾「背景图形」。

## 数据与备份

数据只存浏览器 localStorage，不会上传。换电脑或清理浏览器数据前，
先在「备份」页导出 `.json`，在新机器打开本文件后导入即可恢复。

旧版草稿（安驰抬头的）打开后会自动迁移成捷信通主体，不必手动改。
