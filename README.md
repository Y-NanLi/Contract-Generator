# Contract-Generator 合同 / 报价单生成器

单文件离线网页版报价单生成器，版式按「安驰报价单模板」重排，A4 纵向一页。
不联网、不装软件、数据只存本机浏览器。支持捷信通 / 悦智乐 / 安驰多家公司主体。

## 功能

- **公司主体切换**：捷信通 / 悦智乐 / 安驰 / 只要文字，一键换页首 logo 与发件单位抬头
- 客户 / 我方双栏信息，单号按规则自动生成，日期自动带出
- 明细逐行录入（名称、型号、数量、单价），行金额自动计算；编辑区右下角实时显示合计，单据上不印合计与大写金额
- 明细支持从 Excel 批量粘贴（Tab / 逗号分隔）、回车跳下一行同列、填完自动补空行
- 行操作统一放在表格上方：点任意一行选中（选中行整行变蓝），再用「↑ 上移 / ↓ 下移 / ✕ 删除本行」；选中行按 Delete 也能直接删，不再每行挂按钮
- 数量默认留空（不再预填 1），数量与单价都填了才算金额
- 打印明细只输出真正填了内容的行：删掉的行不会残留，空白行也不打印（一条都没填时才留 1 行空框）；编辑区末尾始终留 1 行空白方便继续填
- 含税价 / 未税价口径切换：只影响表头与编辑区合计，不影响版式
- 条款可增可删（交货期 / 发票 / 有效期 + 自定义条款），序号自动顺排，留空不打印
- 打印明细表列宽可调：直接拖「明细」表头的竖线改列宽，只影响这条线和它右边相邻的一格，其他列不动；表格始终按容器宽度铺满、不会出现横向滚动条，打印表按比例同步；双击竖线或「列宽恢复默认」复位
- 明细表格内长名称 / 长型号自动换行，不截断；「关于」等字段同理
- 自动存本地草稿；「备份」页支持 JSON 导出 / 导入、CSV 导出；「导出全部」把单据、记录库、货品库、客户历史一次带走，「导入货品库」可单独迁移货品
- 右上「打印」直接出纸，右上「导出 PDF」把同一页存成 PDF 文件（同一版式，仅打印面板里的目标不同），A4 纵向一页
- 右上「导出 Word」生成可编辑的 .docx（见下）
- 「版式」页可开电子章（三家章已内嵌，也可上传自己的章图，见下）
- 快捷键：`Ctrl+S` 保存，`Ctrl+P` 打印

### v2.6 新增

- **可以上传自己的电子章**：「版式」页电子章卡片里新增「上传我的章」/「换回内置章」。上传扫描件或手机拍的章图即可（PNG 最好，白底也行），网页自动**去白底**（按每像素红墨浓度算透明度）并**裁掉四周空白、补成正方形**，长边压到 1024px、体积超过约 900KB 自动再缩，保证打印清晰又不撑爆浏览器存储
- 上传的章**按公司主体分别保存**（捷信通 / 悦智乐 / 安驰各家自己的章），换回同一主体自动带出；「换回内置章」一键还原
- **默认位置与大小完全不变**：仍 42mm、压在条款区最左边、0 偏移；上传后照旧用「章直径 / 左右 / 上下 / 角度」四个格子微调
- 上传的章同时用于预览、打印、导出 PDF 与导出 Word（Word 里嵌入的就是这张 PNG）；「导出全部」备份会把上传的章一起带走，导入即恢复

### v2.5 新增

- **「打印」与「导出 PDF」拆成两个按钮**：顶栏不再是一个「打印 / 导出PDF」，改成「导出 PDF」（白底）+「打印」（蓝色主按钮）两个独立入口
- 两个按钮共用同一份打印内容与版式，差别只在最后一步：点「导出 PDF」后确认弹窗会提示把打印面板的「目标打印机」选成 **「另存为 PDF」**（Edge）/ **「Microsoft Print to PDF」**（Chrome），并显示**已自动填好的文件名**（客户名 + 单号），保存时不用再改
- 浏览器不允许网页直接写 PDF 文件（中文需内嵌字体子集），所以「导出 PDF」实质是打印面板里的「另存为 PDF」；这与「打印」用的是同一套 `window.print()`，版式 100% 一致，不会出现两份不同排版
- `Ctrl+P` 也接管为本程序的打印流程（直接交给浏览器会打出空白页，因为打印容器还没生成）

### v2.4 新增

- **货物库只记「规格 + 名称」，不再记价格**：明细行仍然要规格型号、名称、单价三个都填了才入库（缺单价不进库），但库里只存规格与名称
- 规格型号联想弹窗：候选只显示「规格型号 + 名称」（不再带 ￥ 单价）；选中后只补名称，单价每次自己填（已填的字段不覆盖）
- 「货物库管理」列表去掉价格列；货品库导出文件升级为 v2 结构（`[规格, 名称]`），导入时兼容旧的三元组文件，多出来的价格直接丢弃；老库里已存的价格读取时一并忽略

### v2.3 新增

- **客户档案 + 下拉选客户**：「收件单位」点一下弹出老客户列表（输入几个字即筛：前缀优先、再按包含 / 联系人 / 电话匹配，最多 12 条），↑↓ 选择、Enter 确认、Esc 关闭；每行右侧显示该客户的「联系人 · 电话 · 传真」，行尾 ✕ 可把这家从客户库删掉
- **联系方式联动**：选中客户（或手打完整客户名后离开输入框）时，联系人 / 电话 / 传真 / 关于一起带出，预览单据左上同步更新
- **自动建档**：保存单据、导出、载入记录时把当前客户写进客户库（最多 200 家，同名的合并并只更新有新值的字段，不会把已录的电话冲空）；首次打开会把旧单据记录与输入历史里的客户自动补成档案
- 客户库跟着「导出全部」一起备份；联系人 / 电话两格仍保留原生的输入历史下拉

### v2.2 新增

- **电子盖章**：「版式」页勾「加盖电子合同章」，按当前公司主体自动取章（捷信通 / 悦智乐 / 安驰三家，已去白底、按圆外径统一到 42mm，换主体章一样大）
- 默认位置：压在**条款区最左边**（章从正文左边缘起，横向不偏移，正好压在条款文字上；尺寸 42mm，比三行条款高，上下各探出一点，像真盖章）；条款全隐藏时自动退回单据底部
- 可调：章直径（24–70mm）、左右 / 上下偏移（±60mm）、角度（±60°，正数顺时针，模拟手盖斜章）
- 预览、打印 / 导出 PDF、导出 Word 三处同一位置：预览用 CSS 绝对定位，打印把位置复制到 `#printRoot`，Word 用 `wp:anchor`（环绕无、按角度旋转），实测页面坐标与预览对齐
- 章盖在**文字上层**：红墨半透明叠在字与表格线上（真盖章观感），字照样认得出；预览、打印 PDF、导出 Word 都是这个层级

### v2.1 新增

- **导出 Word**：点右上「导出 Word」，直接用网页内嵌的代码拼出真正的 `.docx`（zip + WordprocessingML，零外部依赖、不联网），Word / WPS 打开就是可编辑的文字和表格，不是把网页改后缀的假文档
- 版式与打印一致：页首 logo（图片）、「报 价 单」标题、5 行信息表、明细表（只输出真正填过的行，列宽按当前列宽比例换算 182mm）、条款、签章全部保留；A4 纵向、页边距 12/14mm
- 字号跟随「版式」页的三块系数（标题 / 信息 / 明细），数量单位为 mm、字号换算为半磅，与预览观感对齐
- 文件名与 PDF 用同一规则「客户 + 单号」；导出前自动存草稿、写客户历史与货物库
- 明细多到一页放不下时自然分页，表头在每页重复，条款与签章整体留在最后一页（不会被拆成两半）

### v2.0 新增

- **货物明细库（记忆）**：明细行填齐「规格 + 名称 + 单价」后自动入库（上限 1000 条，同规格合并、最近使用的排前面）；下次只打字就能按规格带出名称（库内自 v2.4 起不再记价格）
- **规格联想**：在「规格型号」格输入时弹出候选（前缀 / 包含 / 空格分词 / 逐字顺序四档匹配，最多 8 条），↑↓ 选择、Enter 补全、Esc 关闭，行尾 ✕ 可直接删掉不要的货品；选中后自动填名称与上次单价（已填的不覆盖）
- **单据记录库**（左侧「记录」）：以前开过的单据全部存着，点「载入」回到原样，「复制成新单」自动换新单号与今天的日期；可按客户 / 单号搜索，列表显示行数与金额；删除给 6 秒撤销
- **版式**（左侧「版式」）：标题 / 信息栏 / 明细三块字号分开调（60–200%），一键「预设」=135/130/115，可复位 100%；「上下偏移」±10mm 整体上下挪动且总高不变、仍是单页；「表格铺到纸底」在明细少时把格线画到页面下方（窗口窄到预览收起时也能正确补行）
- **打印前确认**：打印前弹 4 项检查（A4 纵向 / 边距无 / 取消页眉页脚 / 缩放 100%）；勾「以后不再显示」需手抄「我已阅读且明白」并等满 20 秒，防止手滑关掉提醒（可在版式页重新打开）
- **打印文件名**：自动命名为「客户名 + 单号」（去掉文件名非法字符），导出的 PDF 不用再手动改名
- **输入历史**：收件单位 / 联系人 / 电话三格带下拉候选，取自以前开过的单据（各存最近 30 条）
- **撤销条**：删货品、删记录后底部出现 6 秒撤销条，点一下即还原


## 使用

1. 用 Edge 或 Chrome 打开 `报价单生成器.html`（双击即可，无需服务器）
2. 「我方信息」里先选公司主体，再依次填「单据」→「明细」→「条款」
3. 右上点「打印 / 导出 PDF」；要给别人改的，点「导出 Word」拿一份可直接编辑的 `.docx`

打印设置：纸张 A4、纵向、缩放 100%、取消页眉页脚、不勾「背景图形」。

## 局域网 / NAS 部署（跟着 GitHub 自动更新）

容器只做静态托管，页面还是这一个 HTML，没有后端、没有数据库；单据数据仍存在访问者浏览器里（按访问地址隔离）。

链路：`push 到 main → GitHub Actions 构建 ghcr 镜像 → NAS 上的 Watchtower 每 5 分钟自动换新容器`。

```bash
# 飞牛 / 服务器上（仓库根 compose 就是这套）
docker compose up -d
# 打开 http://这台机器的IP:8090
```

首次不用额外设置：Actions 跑完镜像就是公开可拉的（匿名 `docker pull` 已验证）。若哪天出现 401/denied，去 GitHub 包页面把可见性改成 Public。步骤见 [`部署说明.md`](部署说明.md)。

本地改完不等 Actions，立刻看效果：

```bash
docker compose -f deploy/compose-local.yml up -d --build   # 打本地镜像
docker compose -f deploy/compose-local.yml up -d           # 或改成挂载文件，改完刷新即生效
```

端口刻意用 8090，避开送货单生成器常用的 8088。数据迁移（`file://` → `http://` 必须导一次备份）见部署说明第四节。

## 数据与备份

数据只存浏览器 localStorage，不会上传。换电脑或清理浏览器数据前，
先在「备份」页导出 `.json`，在新机器打开本文件后导入即可恢复。

旧版草稿（安驰抬头的）打开后会自动迁移成捷信通主体，不必手动改。
